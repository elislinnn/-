# Данные

Файл с данными кейса **не публикуется** в репозитории: это материал работодателя.

Чтобы воспроизвести расчёт, положите файл кейса в эту папку под именем `data.xlsx`.
Ноутбук читает его по пути `../data/data.xlsx`.

## Структура файла

**Лист «Пользователи»** — одна строка = один клиент (1 504 строки)

| Колонка | Описание |
| --- | --- |
| `user_id` | ID клиента |
| `group` | Группа теста: A — текущая форма, B — новая |
| `age` | Возраст |
| `city` | Москва / СПб / Регион |
| `device_type` | ios / android |

**Лист «Платежи»** — одна строка = одна попытка оплаты (2 661 строка)

| Колонка | Описание |
| --- | --- |
| `payment_id` | ID попытки |
| `user_id` | ID клиента |
| `group` | Группа теста |
| `step1_opened` | Время открытия формы |
| `step2_entered` | Время ввода реквизитов (пусто — шаг не пройден) |
| `step3_confirmed` | Время подтверждения платежа (пусто — шаг не пройден) |
| `step4_success` | Время успешной оплаты (пусто — оплата не прошла) |
